# ✂️ マルチクロップ

複数のアスペクト比・複数のサイズに対応した画像クロップツール（ブラウザだけで完結）。

🔗 **公開URL**: https://kotoru66.github.io/multi-crop/

## 機能

### 📐 アスペクト比
- 1:1 正方形
- 3:2 横
- 2:3 縦
- 4:3 横
- 3:4 縦
- 16:9 横
- 9:16 縦

### 📏 出力サイズ（5段階・長辺基準）
- 500 / 1000 / 2000 / 4000 px / 原寸

### 💾 保存形式
- JPG（デフォルト）
- PNG
- WebP
- 選択中の保存形式での予想容量を表示

### 🎚️ 画質・圧縮率
- JPG / WebP は画質を選択可能
  - 95% 高画質
  - 80% 標準
  - 50% 軽量
  - 20% 超軽量
- 画質設定に連動した圧縮後プレビューを表示
- 圧縮後プレビューをクリックすると100% / 200% / 400%で拡大表示
- PNGは画質指定・圧縮後プレビューの対象外

### ✂️ 編集機能
- ドラッグ＆ドロップ読み込み（複数画像対応）
- クロップ枠の移動・四隅でリサイズ（アスペクト比維持）
- キーボード微調整（↑↓←→で1px・Shift+矢印で10px）
- センタリング・別画像読み込み
- 三分割ガイド線

### 📊 品質チェック
- FHD / 4K / パン・ズーム / 8K に対応しているか自動判定

### 💡 その他
- 高品質リサイズ
- ファイル名に比率・サイズを自動付与
- アップスケール時に劣化警告
- ダウンロード後に自動で次の画像へ
